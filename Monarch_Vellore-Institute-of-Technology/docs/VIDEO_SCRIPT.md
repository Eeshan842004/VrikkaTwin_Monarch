# Demo video script

A screen recording of the running app (`python -m streamlit run app/Home.py`, http://localhost:8501) with a voice-over.
The narrator **reads numbers from the screen** (every number on screen comes from `reports/*.json`), so nothing in
this script needs updating when a report changes. Keep the browser at 1920 x 1080, zoom 110 %. Mark every persona as
fictional when it first appears. Upload as an **unlisted** YouTube video and paste the link into `README.md`
(`scripts/make_readme.py`, `VIDEO_URL`). Adjust the pacing to the challenge's length rule.
